## 📚 Description

opencode_webui_cli is a user-friendly web UI wrapper for the OpenCode CLI. It helps you access AI-driven tools and chat features without needing to dive into command lines. This application will allow you to interact with powerful tools through an easy-to-use interface.

## 🖥️ Features

- **User-Friendly Interface**: Navigate the tools with ease using our intuitive layout.
- **AI Integration**: Leverage AI capabilities directly from your browser.
- **Chat Functionality**: Engage with chat features for quick assistance and information.
- **Cross-Platform Support**: Works on Windows, macOS, and Linux systems.
